ONE-TIME SETUP

Connect your Gmail

Mailsome needs a Google OAuth client before you can sign in. Create one in your own Google Cloud project, then upload its JSON file here. No manual file copying needed.

Use the same project throughout these steps. Mailsome requests Gmail modify access to read mail and assign labels. This permission also permits sending, but Mailsome does not implement sending or deletion, and opening mail does not mark it read.

  1. Create a project and enable the Gmail API

    Open Google Cloud, create a project named Mailsome, and select it. Then open the Gmail API page and click Enable.

  2. Configure the consent screen

    Open Google Auth Platform and choose Get started if prompted. Set the app name to Mailsome and enter your support/contact email.

    For a personal Gmail account, choose the External audience. Keep the app in Testing and add your Gmail address under Audience → Test users.

    Under Data Access → Add or remove scopes, add this scope and save:

    https://www.googleapis.com/auth/gmail.modify

  3. Create a Web application OAuth client

    Go to Clients → Create client. Choose Web application (not Desktop app) and name it Mailsome local.

    Add this exact address under Authorized redirect URIs. You can leave Authorized JavaScript origins empty.

    http://localhost:8002/auth/callback

    Click Create and download the client JSON while it is available. The downloaded name may start with client_secret_—you don’t need to rename it.

  4. Upload the JSON and continue

    Saved only on this machine as data/credentials.json, with owner-only permissions. Existing credentials are never overwritten. Maximum file size: 64 KB.

Creating the client does not grant mailbox access. Next, Google will ask you to sign in and approve Gmail modify access. While your app is in Testing, Gmail refresh tokens expire after seven days; reconnect when prompted.

Need more detail? See Google’s OAuth client setup guide.
